# BITACORA

La BITACORA es un registro rotativo de trabajo.

## Protocolo
- El OBRERO lee la bitácora vigente al comenzar.
- Durante su ciclo de trabajo registra mentalmente el estado anterior.
- Al finalizar genera una nueva bitácora con:
  - fecha/ciclo;
  - objetivo;
  - trabajo realizado;
  - archivos modificados;
  - decisiones nuevas;
  - problemas;
  - pruebas realizadas;
  - siguiente tarea concreta.
- La nueva bitácora reemplaza a la anterior.

## Importante
La rotación de la bitácora NO debe alterar CREREBRO.md ni ESQUEMA/.
No usar la bitácora para almacenar decisiones maestras permanentes.
